# polysearch

[![CI](https://github.com/so1ve/polysearch/actions/workflows/ci.yml/badge.svg)](https://github.com/so1ve/polysearch/actions/workflows/ci.yml)

An in-memory fuzzy search library for Rust, suited to launchers, command palettes,
and local search. Supports prefixes, substrings, abbreviations, and common typos.

> [!NOTE]
> Most of the code in this project was generated by AI. I've done my best to review it
> and have made many improvements to the search behavior. If you don't like that,
> don't use it.

## Documentation

[![Documentation](https://docs.rs/polysearch/badge.svg)](https://docs.rs/polysearch)

## Example

```rust
use polysearch::{Config, Entry, Field, PRIMARY_NAME, Searcher};

let searcher = Searcher::new(
    [Entry {
        id: 1,
        fields: vec![Field {
            id: 1,
            role: PRIMARY_NAME,
            text: "文档助手".into(),
        }],
    }],
    Config::default(),
);

let results = searcher.search("文档", 10);
for result in results {
    println!("entry={}, field={}", result.entry, result.field);
}
```
